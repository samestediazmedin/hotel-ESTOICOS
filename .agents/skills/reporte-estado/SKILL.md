# Skill: Reporte de Estado Estructurado

## Cuándo Usar
Al finalizar cualquier sesión de trabajo, fase de proyecto, o cuando el usuario solicite un resumen de progreso.

## Instrucciones
1. Analiza toda la información del trabajo realizado en la sesión actual
2. Genera un reporte usando el formato Markdown obligatorio de 4 secciones
3. Aplica las restricciones de estilo (sin introducciones, directo al grano)

## Formato Obligatorio

### 1. 🎯 RESUMEN EJECUTIVO
- Máximo 3 líneas, un párrafo
- Estado de salud general + valor entregado

### 2. ✅ LO QUE SE HIZO (LOGROS)
- Verbos en pasado
- Dividir por componentes si aplica
- Solo tareas completadas/cerradas

### 3. 🚀 PRÓXIMOS PASOS
- Accionables claros
- Priorizados

### 4. ⚠️ BLOQUEOS O RIESGOS
- Objetivo y específico
- "Ninguno detectado" si no hay

## Restricciones
- NO introducciones tipo "Aquí tienes..."
- Tono técnico pero accesible
- Inconsistencias → sección de riesgos
- Directo al grano siempre
