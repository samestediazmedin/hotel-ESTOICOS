<threat_model>
- **Silent field drop (CRITICAL)**: `GuestsService.create()` uses explicit `data: {...}` mapping — NOT spread. If the executor extends Zod but forgets to add fields to the mapping, Prisma silently persists `null` for the new columns. Unit test MUST assert the new fields are passed to `repo.createGuest`.
- **E.164 regex injection vector**: `whatsappNumber` accepts user input. Zod regex `/^\+[1-9]\d{6,14}$/` enforces strict format — no spaces, no parentheses, no extension digits — preventing injection of control chars later concatenated into HTML or `tel:` links downstream (Phase 16).
- **Marketing consent legal (Ley 1581 Colombia)**: BOTH Prisma `@default(false)` AND Zod `.default(false)` MUST be `false`. Pre-checked opt-out boxes are non-compliant. Migration SQL must show `DEFAULT false`.
- **Migration timestamp collision**: Use `20260519000001` strict — anything `<= 20260519000000` would be applied out-of-order and Prisma migrate would fail with `P3009`.
- **Enum DDL order**: `CREATE TYPE` MUST execute BEFORE `ALTER TABLE ... ADD COLUMN "contactPreference" "ContactPreference"`. Prisma generates this order automatically but executor must verify in the generated SQL.
</threat_model>
