# Milestone v1.7 — Guest Experience Enhancement

## Objetivo
Cerrar las features diferidas del v1.3 carry-forward que impactan directamente la experiencia del huésped y reducen carga operativa del staff.

## Features incluidas

### 1. Pre-arrival Reminder Cron (HIGH)
- Enviar email recordatorio 1 día antes del check-in
- Incluir: hora de llegada, dirección, contacto, instrucciones especiales
- Usar Resend + plantilla HTML inline
- Cron job en NestJS ScheduleModule (04:00 Bogotá)

### 2. Email Templates Library (MEDIUM)
- Crear sistema de plantillas reutilizables para:
  - Welcome email (post-booking)
  - Pre-arrival reminder
  - Thank-you / review request (post-checkout)
  - Booking confirmation (refactor existing)
- Plantillas en español con soporte para inglés (preparación i18n)
- Admin puede editar variables (hotelName, tagline, etc.)

### 3. Online Reservation Completion via Portal (HIGH)
- Permitir que huéspedes completen reserva existente desde el portal
- Estado "PENDING_COMPLETION" para reservas iniciadas pero no pagadas
- Flujo: buscar reserva por email + código → ver detalles → completar pago
- Integración con pasarela de pago (diferida, pero preparar estructura)

### 4. Documentación Retroactiva v1.0 MVP (MEDIUM)
- Crear PLAN.md + CLOSEOUT.md para fases 01-08
- Documentar decisiones técnicas clave
- Crear QA Checklists para cada fase
- Esto es deuda técnica de documentación

## Stack
- NestJS ScheduleModule (cron)
- Resend (email)
- React + TanStack Query (portal)
- Prisma (migrations)

## Success Criteria
1. Cron envía recordatorios automáticamente sin intervención humana
2. Staff puede ver qué huéspedes recibieron recordatorio
3. Portal permite completar reservas pendientes
4. 4 plantillas de email funcionando
5. Documentación v1.0 completa en .planning/

- Tests: 1,566+ nuevos (mantener 100% pass)
- 0 vulnerabilidades
- 0 errores TS
- Coverage no debe bajar
